04 / ARCHITECTURE DECISIONS

Every technical choice
has a reason.

ADR-001 Why microfrontends?

Business modules can evolve independently while the App Shell owns cross-cutting concerns. This is justified only when team boundaries and release independence create real value.

ADR-002 Why a shared Design System?

Independent modules should still feel like one product. Shared Web Components and tokens reduce visual drift and duplicate UI decisions.

ADR-003 Why tenant isolation at the database layer?

Application checks are necessary but not the only defense. PostgreSQL Row-Level Security provides an additional boundary around tenant-scoped data.

ADR-004 Why controlled AI context?

The assistant should answer from permitted business context rather than inventing access. Retrieval and authorization remain architectural concerns, not just prompt concerns.
